# fract-ol

## Description

fract-ol is a fractal exploration program that renders beautiful mathematical fractals in real-time using the MiniLibX graphics library. The project demonstrates computer graphics programming, complex number mathematics, and event-driven programming.

The project includes:
- **Mandelbrot set**: Classic fractal generated by iterating z = z² + c
- **Julia set**: Dynamic fractal with customizable complex parameters
- **Real-time rendering**: Interactive exploration with zoom and pan controls

Available fractals:
- `mandelbrot`: The iconic Mandelbrot set fractal
- `julia`: Julia set with custom complex number parameters

This implementation uses the **escape-time algorithm** where each pixel represents a complex number. The program iterates a mathematical formula and colors the pixel based on how quickly the value "escapes" to infinity. Colors are dynamically generated using RGB modulation based on iteration count.

**Rendering Flow:** Map pixel to complex plane → Iterate fractal formula up to max iterations → Assign color based on escape time → Display image to window

## How It Works

1. **Initialization**: 
   - Creates window (800x800 pixels)
   - Initializes zoom level (1.0) and view center (0, 0)
   - Sets maximum iterations (100)
2. **Pixel mapping**: 
   - Each pixel coordinate (x, y) is mapped to a complex number (re, im)
   - Mapping accounts for zoom level and view offset
3. **Fractal calculation**:
   - **Mandelbrot**: Iterates z = z² + c where c is the pixel's complex number
   - **Julia**: Iterates z = z² + c where z starts at pixel and c is constant
   - Counts iterations until |z| > 2 or max iterations reached
4. **Coloring**:
   - RGB values calculated from iteration count
   - Creates smooth color gradients
   - Black color for points in the set (max iterations)
5. **Display**: Rendered image pushed to window using MiniLibX

## Mathematical Background

### Mandelbrot Set
The Mandelbrot set is defined by the iteration: **z(n+1) = z(n)² + c**
- z starts at 0
- c is the complex number corresponding to the pixel
- A point is in the set if |z| remains bounded after infinite iterations

### Julia Set
The Julia set uses the same formula: **z(n+1) = z(n)² + c**
- z starts at the complex number corresponding to the pixel
- c is a constant complex parameter (provided by user)
- Different c values create entirely different fractal shapes
